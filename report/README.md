# Internship report

*Smoothed Duality Gaps Beyond Convexity: KKT Detection, Pointwise Smoothing
Thresholds, and Proximal Escape under Affine Constraints* — `main.pdf`.

## Structure

| File | Content |
|---|---|
| `sections/00_abstract.tex` | Abstract |
| `sections/01_introduction.tex` | Motivation and contributions |
| `sections/02_preliminaries.tex` | Weak convexity, proximal maps, level-proximal subdifferential |
| `sections/03_sdg.tex` | Self-centered SDG and exact KKT detection for `β_x > ρ` |
| `sections/04_thresholds.tex` | Pointwise smoothing thresholds and false zeros |
| `sections/05_escape.tex`, `05b_affine_prox.tex` | Proximal escape and affine-constrained proximal duality |
| `sections/07_experiments.tex` | Experiments (data from `../experiments/`) |
| `sections/08_discussion.tex` | Discussion and limits |

## Build

From this folder:

```bash
latexmk -pdf main.tex      # or: tectonic main.tex
```

Section 6 includes tables and figures generated by `../experiments`
(`python -m sdg_report_experiments`), so keep both folders side by side.
The schematic figures in `figures/` are produced by the scripts in `scripts/`:

```bash
python scripts/make_sdg_schematic.py
python scripts/make_affine_quartic_geometry.py
python scripts/make_threshold_diagnostics.py
python scripts/make_proximal_escape_schematic.py
```
